Objective 2 · Trace the cause

Three things, in order

A no-start is almost never a mystery. It is a missing one of three things, and the order you check them saves time.

An engine needs air, fuel and spark. When it turns but does not catch, one of those three is absent or arriving at the wrong time. The skill is not knowing the list; it is choosing which one to test first so the next test is cheaper than the last.

Start with what you can hear. A single long crank with no cough points away from spark. A cough that dies points toward fuel delivery. Write down what you heard before you open anything, because the engine will not repeat the clue once it is warm.

Only then reach for a tool. The compression check at the end of this section exists to confirm a suspicion, not to replace listening.
