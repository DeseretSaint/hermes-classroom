What this course will not teach

  • Fractions, unit conversion or reading a scale finer than the 50 ml marks.
  • Any hazard: the pack uses water and a jug, with no heat, sharp tools or chemicals.
  • A child-facing chat: this recipe is parent-led, and the parent records what happened.

From the creator

Prepared for a parent to run, not for a child talking to a tutor. The learner page carries the two tasks; the answer guide is a separate file the manifest declares by role.
