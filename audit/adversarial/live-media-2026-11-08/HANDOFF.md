## 2. Not captured — stated, not hidden

- **No cost figure.** Neither host tool returned a price, and no gateway invoice or usage export
  was read. `image_generate` returned `duration_ms: 4725` and `tokens: {}`; `text_to_speech`
  returned neither. `MANIFEST.json → cost.total_recorded_usd` is `null`, not `0`.
- **No TTS model id.** The host text-to-speech tool does not report one; the artifact row stores
  `model: "host-configured"`. The image model *is* known (`fal-ai/flux-2/klein/9b`).
- **No spoken-content check.** There is no local speech recogniser on this host, so the MP3's
  phonemes were never transcribed. Format, duration, frame sync and energy were verified — the
  words were not machine-checked.
- **No live Electron window.** The UI probe mounts the shipped plugin in jsdom with the repo's SDK
  stub (the same seam its own desktop suites use) and feeds it the real page and real `/media/`
  payloads. It is a render of the shipped module, not a screenshot of a running app.
- **No host auth layer in the HTTP probe.** The ASGI probe mounts the shipped router without the
  host's `/api/` auth middleware; auth is the host's gate and was out of scope.
- **No bytes for the required schematic.** `gen_tech_1`'s required `schematic` stays text-only
  (`degraded: true`, text equivalent kept). Policy allows a required image only as a deterministic
  schematic or a cited sourced reference, never as a required AI illustration, so this was left
  alone rather than filled with a generated picture. Not a defect; not a capture.
- **The lesson content is not live model generation.** This is the biggest caveat in the package.
  The two courses and their lessons were prepared by a script (`t_ac36aad4`,
  `audit/adversarial/h187-course/`), not authored by a live model pass on this tree. Their rows
  are `model_assessed` with `validation_id = NULL`, and every served page carries
  `provenance.independent: false` with the warning “model assessed, not independently validated:
  treat this page as a proposal.” What is live here is the **media pipeline**, exercised end to end
  against real providers; what is not live is the **pedagogy**. Earlier live end-to-end attempts
  (`t_740005f6`, rounds 2–9) never reached an approved plan on this tree and produced zero media
  calls — that history is why this package exists in this shape.

## 3. Provider availability on this host

- `text_to_speech`, provider `openai` through the **Nous audio gateway** (`tts.use_gateway: true`
  in the prepared home's `config.yaml`): **available**, 41,088-byte MP3.
- `text_to_speech`, the host's own default fallback **`edge`**: **unavailable** on this host —
  `TTS generation failed (edge): No audio was received. Please verify that your parameters are
  correct.` That first attempt degraded honestly (text-only, 0 artifact rows) and was then fixed by
  writing the one-line host TTS selection into the prepared home. The failed attempt is kept in the
  source record; it is not erased by the success.
- `image_generate`, **managed fal queue** (`FAL_KEY` unset, gateway-managed): **available**,
  598,928-byte PNG, model `fal-ai/flux-2/klein/9b`.
- No media provider was unreachable during the captures that produced these two artifacts. The
  generation *stage* upstream of media was the part that kept failing on this tree (plan
  validation and lesson deadlines); that is a separate, documented failure, not a media-provider
  outage.

## 5. Redaction

Every file in this package was scanned for credential-shaped strings (OpenAI-style `sk-` keys,
GitHub tokens, AWS key ids, Slack tokens, `Bearer` headers, private-key blocks, `FAL_KEY=`
assignments, literal `api_key` fields). **Hits: 0.** The prepared home's `config.yaml` selects
`tts.provider: openai` with `use_gateway: true` and carries no key; the image path ran on the
managed fal queue with `FAL_KEY` unset. The image tool's returned retrieval URL (in
`sources/capture_evidence.json`) carries no query string or signature and is not a credential.
If a hit had existed it would have been replaced with `<REDACTED:pattern@file:offset>` and only its
digest recorded. See `MANIFEST.json → tokens_and_redaction`.
