## Wording and usage

**Wiktionary — 好き (suki)** · source type: reference · support: model_assessed
<https://en.wiktionary.org/wiki/%E5%A5%BD%E3%81%8D>

Used for: `好き` is a na-adjective describing what is liked; `好きです` is its formal form; the
entry records `好きです` as idiomatically used to express "I love you".

**Wiktionary — 愛する (aisuru)** · source type: reference · support: model_assessed
<https://en.wiktionary.org/wiki/%E6%84%9B%E3%81%99%E3%82%8B>

Used for: `愛してる` (aishiteru) is the continuous form of `愛する` ("to love"); the entry's
example glosses `愛してる` as "I'm in love with you".

**Shinjuku Japanese Language Institute (SNG) — "Learn how to say 'I love you' in Japanese"** ·
source type: secondary · support: model_assessed
<https://www.sng.ac.jp/sng-news/learn-say-love-japanese/>

Used for: a confession commonly takes the shape `好きです。付き合ってください。`; `愛してる` is real
but should not be overused; affection in Japan is often shown through actions. SNG is a language
school publishing learner guidance, not a linguistic authority, so this is labelled secondary.

**Wikipedia — Honorific speech in Japanese** · Wikimedia Foundation · source type: reference ·
support: model_assessed
<https://en.wikipedia.org/wiki/Honorific_speech_in_Japanese>

Used for: `です`/`ます` is polite addressee language (teineigo); in-group/out-group (内/外,
uchi/soto) thinking shapes honorific choice. Wikipedia is a tertiary summary; it is used only for
this general framing, not for any specific wording claim.
