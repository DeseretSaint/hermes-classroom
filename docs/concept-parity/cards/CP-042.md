# [CP-042] Ship the bundled packs as real store courses, not fixtures

Owner `cbqa`, reviewer `atlas`, 90m, worktree branch `wt/cp-042-pack-shipping`.

Owner ruling (2026-11-10): the courses that ship with the plugin are real courses a user adds to their library from the store. Nothing user-visible says demo, sample or fixture. Our own use of them for the launch film is incidental.

Current state, verified: three packs ship under `bundled/packs/`. Their titles are "Japanese affection and register — a Sample L0 classroom", "Parent demo: measuring ingredients together", "Technical demo: reading a pack before you install it"; every license is `unspecified` with a note beginning "Bundled demonstration fixture", and `redistribution` is `local_only`. A user opening Discover sees demo fixtures, and the packs cannot legally be redistributed as they stand.

Do:
1. Titles and identity. No user-visible string may match /demo|sample|fixture/i.
   - `japanese-affection-context-l0`: title "Japanese register: affection and closeness"; keep the pack id.
   - `parent-measurement-practice`: title "Measuring together: a kitchen lesson"; keep the pack id.
   - `technical-demo-pack`: rename the directory to `bundled/packs/technical-pack-literacy` and the `pack_id` to `technical-pack-literacy`; title "Reading a pack before you install it". Update every reference (builder, tests, fixtures, docs).
   - Subtitles and level labels: real course language, no sample/demo wording.
2. Licences. Text: `CC-BY-4.0`, `redistribution: allowed`. Per-artifact covers: `CC-BY-4.0` with the attribution "Model-generated cover produced for this pack; no third-party source or media." Remove every "demonstration fixture" note. The owner's direction to ship these in the store is the redistribution decision; record it as "Operator-directed redistribution, 2026-11-10" in the license note.
3. Builder. Rename `bundled/packs/build_demo_packs.py` to `build_bundled_packs.py`, update its docstring (no "demonstration"), and regenerate all three manifests so `content_hash` and file hashes match. Determinism must hold: two runs byte-identical.
4. Tests. Update `tests/test_packs_fixtures.py` and `tests/test_h197_covers.py` where they assert `local_only`/`unspecified`. Add `tests/test_pack_shipping_labels.py`: every bundled pack has a licence id other than `unspecified`, `redistribution == "allowed"`, and no user-visible metadata field (title, subtitle, level_label, license.note, attribution, contributors) matches /demo|sample|fixture/i.
5. Proof. On a fresh `HERMES_HOME` with the plugin installed, `workshop.list` shows three entries with the new titles, and `workshop.install(pack_id)` for each puts the course in the library and opens it. Record the JSON output and, if `scripts/cp-capture.mjs` can reach Discover, one stamped frame.

Done when: `packs.validate_manifest` passes for all three, the full suite is green, the install proof is in the summary, and no user-visible pack metadata contains demo, sample or fixture.
