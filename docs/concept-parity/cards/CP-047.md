Build an isolated lab for the 12 v3 primitives and adopt correct keyboard/ARIA behaviour instead of hand-rolling it. Done when: every primitive has a story with its states (default, hover, focus-visible, disabled, loading, error), the lab renders without the host, axe is clean on every story, and the production components consume the same state machines rather than duplicating key handling.
